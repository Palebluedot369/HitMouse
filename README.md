# 打地鼠

## 项目简介
基于MOOC课程学习，独立完成的2D休闲游戏。实现了完整的游戏循环：开始游戏 → 点击地鼠计分 → 30秒倒计时 → 结束场景展示本轮得分与历史最高分。

## 技术栈
- **引擎**：Unity 2022.3.62f1c1
- **语言**：C#
- **数据存储**：PlayerPrefs（最高分持久化）
- **版本控制**：Git

## 核心功能
- **场景管理**：开始场景、游戏场景、结束场景之间的切换与数据传递
- **游戏核心**：地鼠随机生成、点击计分、30秒倒计时、分数实时UI更新
- **最高分记录**：使用PlayerPrefs存储历史最高分，并在结束场景对比显示
- **再来一局**：结束场景提供按钮，一键返回开始场景

## 个人贡献

- 实现最高分存储与跨场景数据传递
- 调试并解决了地鼠生成位置重叠、地鼠数量较少等问题

## 如何运行
1. 使用 Unity 2022.3 或更高版本打开项目。
2. 打开 `Assets/Scenes/StartGame.unity` 场景。
3. 点击运行，点击“开始游戏”即可。
